# BmCBP 基材定性证据分级

本分级用于整理保存下来的织物照片和文字记录，不把主观观察转换为仪器色牢度等级。

| evidence_class | 使用条件 | 当前记录 |
|---|---|---|
| `strong_qualitative_support` | 同一基材有可辨识的实验组/对照组与洗前/洗后记录，方向在平行记录中一致 | 丝绸 |
| `weak_qualitative_support` | 记录显示部分颜色保留，效果弱于强支持基材，缺少可复核的仪器测量 | 棉、聚酯 |
| `control_reference` | 作为配方或组别对照，不单独生成材料效果结论 | Control 1、Control 2 |
| `unresolved_formulation` | 图中存在该组别，公开记录无法恢复完整配方 | Control 3 |

`BmCBP_Fastness` 表不再使用 1–5 数值评分。跨基材顺序只表达证据强弱，不表示可比较的色牢度差值。Fig.46 的组别方向以完整配方、成对图片和平行结果联合校正；Fig.48 Control 3 的配方保持未恢复状态。
