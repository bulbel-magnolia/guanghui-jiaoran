# BmCBP 实验记录摘要

## 元件与表达设计

实验使用密码子优化的截短 BmCBP 编码序列。该序列对应 UniProt Q8MYA9 第 68–297 位氨基酸，去除 N 端第 1–67 位预测无序区，当前 CDS 为 690 bp。实际表达依赖 pET-28a 提供的翻译起始和融合表达上下文。

## 结合测量

每个 BmCBP 浓度条件进行 3 次测量。随着 BmCBP 浓度增加，平均 A480 依次下降，支持 BmCBP 与虾青素结合。

| BmCBP 浓度（mol/L） | 平均 A480 | 游离 astaxanthin（mol/L） |
|---:|---:|---:|
| 0 | 2.19190 | 1.6×10⁻⁶ |
| 5.5×10⁻⁷ | 2.00360 | 1.4×10⁻⁶ |
| 1.1×10⁻⁶ | 1.84980 | 1.2×10⁻⁶ |

重复字段为 `n = 3 measurements per condition`。当前结构化数据保存平均 A480；三次原始值恢复后可作为增强数据补入。现有结果未生成 SD、SEM 或误差线。

A480=1.84980 时，原表报告 0.761 mg/L；按 ε=2365 L/(g·cm)、1 cm 光程直接计算得到 0.782156 mg/L，相差约 0.021156 mg/L。两个数值均保留，并在结构化表中标记公式差异状态。

## 基材反馈

丝绸、棉和聚酯的洗前/洗后记录采用定性证据等级。丝绸形成最明确且方向一致的固色支持，棉和聚酯形成较弱的颜色保留记录。分级规则见 [BmCBP 基材定性证据分级](bmcbp-qualitative-evidence-rubric.md)。

Fig.46 的一处图注与完整配方、成对图片和平行结果所支持的组别方向相反，公开叙事采用完整记录支持的方向并在冲突表中保留原记录。Fig.48 Control 3 的配方状态保存为 `unresolved_formulation`。
