# Collaboration · 团队合作

FABRIC 在项目推进过程中与高校 iGEM 团队、产业单位和跨学科专家持续交流。合作内容覆盖可持续发展科普、软件可视化、硬件远程控制、工艺标准化和工业化评价。团队合作中最完整、可双向核查的成果，是与 NUDT-CHINA、SCU-China 共同完成的合成生物学与可持续发展主题手册。

---

## 1. 与 NUDT-CHINA、SCU-China 联合编写可持续发展手册

2025 年 8–9 月，BIT-China、NUDT-CHINA 与 SCU-China 围绕“合成生物学如何参与可持续发展目标”共同编写主题手册。三队将不同项目经验组织为面向公众和跨领域读者的案例材料，使合成生物学与 SDGs 建立更直接的联系。

三队形成了明确分工：

| 队伍 | 主要贡献 |
|---|---|
| BIT-China | 负责主要文字内容与案例组织 |
| NUDT-CHINA | 参与内容讨论、翻译与可视化 |
| SCU-China | 参与内容讨论、翻译与可视化 |

这一合作形成了可复用的教育材料，也把三支队伍各自的项目从单一技术问题扩展到社会、环境和可持续发展语境。

### 双方/多方互证

## 2. 团队交流如何推动项目迭代

### 清华大学探微书院 iGEM 团队

团队交流聚焦工业评价标准和色素稳定性。对方建议进一步对齐产业性能指标，并从实验效率角度讨论色素储存与后续转化。这些意见推动 FABRIC 在湿实验与应用评价中更加重视标准化和产品稳定性。

### 南京师范大学 iGEM 团队

双方介绍项目后，对方重点关注团队开发的软件，并建议增加更多可视化功能。该意见被纳入后续软件界面和结果展示优化。

### 华中科技大学团队

双方交流社会实践工作。对方认可 FABRIC 将传统染色文化与合成生物学结合的方向，并建议进一步扩大公众参与范围。该意见强化了项目在人类实践和科普中的文化表达。

### 北京师范大学珠海校区团队

硬件交流为 FABRIC 的远程控制和系统集成提供了参考。团队重点吸收对方远程控制系统的工程逻辑，并将相关思路用于光控硬件的通信与监测设计。

### CCiC 交流

FABRIC 在 CCiC 展示后，多支队伍集中询问工艺可行性和标准化。团队据此开展棉、丝绸和聚酯的比较实验，使“基材差异”从讨论问题转化为实际测试变量，并进入 P1 Material Interface Optimizer 的材料优先级更新。

## 3. 产业合作与工程化交流

团队还与 JABIO Biotech 等产业单位交流发酵放大、分离纯化、废水处理和副产物资源化。产业反馈帮助团队将实验室模块放到更完整的生产链中考虑，并补充规模化、稳定性和成本控制等工程问题。

这些交流与高校团队合作共同推动 FABRIC 从“能否实现”进一步走向“如何标准化、如何扩展、如何让其他人复用”。
