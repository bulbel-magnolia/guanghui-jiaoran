# Design · 系统设计

FABRIC 采用模块化架构，把生物色素生产、材料固色和可编程光控拆分为 P0/P1/P2 三个技术模块，并通过实验记录与反馈模块统一记录来源、实验结果、模型输出和下一轮安排。

## 1. 设计原则

### 模块化

P0、P1、P2 分别保存实验和计算结果，并使用统一的数据格式交换信息。各模块独立记录版本，更新时保留其他模块的已有结果。

### 可验证

每个关键结论都对应具体数据、代码或实验记录。团队先审核模型建议，再选择实验对象；实验完成后，程序按已记录版本的规则更新评价结果。

### 可迭代

系统保存候选、选择依据、证据等级和下一轮安排。设计阶段与实验反馈阶段分别使用各自的数据，基准比较不读取后续实验结果。

---

## 2. 四层架构

| 层级 | 输入 | 输出 |
|---|---|---|
| **P0 生产优化模块** | Round 0、共同模型、GPR、Round 1 | 全候选表型、候选优先级、证据等级、下一轮安排 |
| **P1 材料固色模块** | BmCBP、结合测量、洗涤与基材 | 结合趋势、材料优先级、固色方案 |
| **P2 颜色与光控模块** | 颜色、混色、光响应、数字图案 | 颜色候选、光参数、投光接口 |
| **实验记录与反馈模块** | 来源、版本、实验状态、规则 | 输入来源、计算过程、数据冲突和发布前核对 |

---

## 3. P0 关键设计

### 3.1 共同模型与候选空间

2026 基准比较使用 Yeast-GEM v9.1.0 与 FABRIC 异源产色通路建立共同模型。修订后的主分析候选空间包含 **235 个单基因敲除**，依据完整的基因—蛋白—反应（GPR）布尔规则，确定每个基因敲除导致的失活反应集合。

### 3.2 两阶段决策

**设计阶段** 负责公开基准比较和实验前候选评价，不读取 Round 1 PAN5/MDE1 结果。系统计算生长保持、不同生长要求下的 Pmin/Pmax、近最优生长下的 Pmin95/Pmax95、GCP、PCR 和敲除后的失活反应集合。

**实验反馈阶段** 在设计结果固定后读取湿实验终点产量、持续性、生物量与可实施性，更新证据等级和下一轮安排。

<a id="33-非区分检测"></a>
### 3.3 产物下界区分度检查

主分析条件下，若全部候选的 GCP 与 Pmin95 均为 0，系统判定产物下界无区分度，并按预先设定的可实施性规则排序。相关状态码与排序顺序见 [AI / 计算方法](./AI-Computational-Methods.md)。

## 4. P1 关键设计

P1 按以下步骤评价材料：

`蛋白候选 → 表达纯化 → 虾青素结合 → 织物实验 → 材料优先级`

分子对接用于选择 BmCBP 候选；A480 和游离色素测量用于评价结合；丝绸、棉和聚酯实验用于比较基材。产业反馈进一步提出加入壳聚糖物理保护层的双层固色方案。

---

## 5. P2 关键设计

P2 分别记录颜色、光响应参数和硬件控制信息：

1. **颜色候选池**：保存已观察单色、混色、培养物/提取物和基材状态；
2. **光响应参数**：保存 PhiReX 等光控系统的波长、光强、脉冲照射时长和归一化读出；
3. **硬件执行层**：将数字图案转换为空间化或时序化光输入，并通过光传感、图形界面、4G 通信和远程控制实现参数调整。

---

## 6. 关键技术决策

| 决策 | 采用方案 | 设计依据 |
|---|---|---|
| 生产优化候选空间 | 统一 235 个单基因敲除候选的共同空间 | 便于与近期公开基线进行公平基因水平评价 |
| 生产评价 | GCP/Pmin95、生长保持、PCR、失活反应数 | 同时记录产物通量下界、生长和理论产能保留 |
| 多条件评价 | v1 主条件 + v2A 生产阶段敏感性 | 保持同一主分析候选集合，观察生产阶段依赖 |
| 排序 | 固定字典序规则 | 按同一规则重复计算可得到相同顺序 |
| BmCBP 验证 | 表达纯化 + 结合 + 织物 | 直接评价材料接口功能 |
| 光控读出 | EGFP/OD600 | 同时考虑表达信号和生物量 |
| 硬件控制 | 光传感 + 图形界面 + 4G | 支持监测、调整和远程控制 |

---

## 7. 安全与人工审核接口

模型输出先进入团队人工复核，再转化为实验对象。软件不自动下发菌株构建、培养或实验设备命令。当前公开 Production Optimizer 处理既定共同模型和候选空间，不生成新的生物序列。

详细计算流程见 [AI / 计算方法](./AI-Computational-Methods.md)，工程迭代见 [工程化循环](./Engineering-Cycle.md)。
