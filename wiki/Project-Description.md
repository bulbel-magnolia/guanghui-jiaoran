# Project Description · 项目描述

## 1. 项目问题

传统纺织染色通常依赖高耗水、高能耗和多步骤化学处理。生物制造为天然色素生产提供了新的路线，真正进入纺织场景还需要同时解决三个问题：**色素产量、织物界面稳定性和可编程图案表达**。

光绘酵染以工程化酵母为生产底盘，以 BmCBP 连接色素与织物，以光控表达和数字投光连接颜色目标与空间图案。FABRIC-AI 进一步把代谢计算、材料实验、光控数据和湿实验反馈组织为统一的设计—验证—学习流程。

---

## 2. P0：Production Optimizer

P0 解决“哪些代谢干预值得进入实验”。Round 0 发酵记录进入 Yeast9/FBA/OptKnock 分析，历史页面形成 307 个候选反应与 Plan1–Plan14。团队结合代谢通路、文献证据和实验可实施性，确定 `RIB2`、`PAN5`、`MDE1`、`MRI1`、`SPE2`、`FUM1` 六个 Round 1 靶点。

Round 1 提供真实反馈：ΔPAN5 在 120 h 约 `0.67 mg/L`，同批 AST 约 `0.47 mg/L`；ΔMDE1 在 96–120 h 由约 `0.42 mg/L` 降至 `0.36 mg/L`。反馈规则将终点产量、后期持续性、生物量保持和可实施性写入证据等级，形成下一轮优先级。

2026 benchmark 版本将这一研究结构固化为可执行 Production Optimizer v1.2。系统在 corrected 235-gene 空间内对全部候选进行表型计算，并在主葡萄糖条件与乙醇生产阶段敏感性条件下进行一致评价。近三年公开基线 FastKnock、CFSA、OptEnvelope 与本队方法均在冻结共同模型下完成复现与比较。

---

## 3. P1：Material Interface Optimizer

P1 解决“如何让天然色素更稳定地连接到织物”。BmCBP 具有类胡萝卜素结合能力，团队以功能分析和分子对接建立候选依据，随后完成截短 BmCBP 的表达、纯化、A480 结合和跨基材验证。

三个 BmCBP 浓度条件各进行 3 次测量，平均 A480 随 BmCBP 浓度增加由 `2.19190` 降至 `2.00360` 和 `1.84980`。丝绸、棉和聚酯的比较用于更新材料优先级，丝绸形成当前最明确的实验支持。

Human Practices 的产业交流进一步推动“BmCBP 蛋白媒染 + 壳聚糖物理保护”的双层固色方向，使分子结合和产品稳定性进入同一材料决策流程。

---

## 4. P2：Color & Light Translator

P2 解决“如何把目标颜色转化为可执行光输入”。系统保存单色、混色、培养物/提取物和基材状态，并将已有颜色记录与光响应参数组织为可查询的候选池。

PhiReX 红光实验采用约 `630 nm`、`200 μW/cm²`、2 h pulse 和 24 h 总培养时间。培养结束后测量 EGFP Ex/Em `485/528 nm` 与 OD600，R5、R11、R13 三个编号样品在红光条件下均高于无光对照。

硬件将数字图案转换为空间化或时序化光输入，并通过光传感、GUI、4G 通信和远程参数调整连接培养状态与投光控制。

---

## 5. AI + 合成生物学如何形成闭环

FABRIC-AI 的作用不是单独输出一个预测值，而是把计算结果转化为实验决策，并让实验结果继续影响下一轮设计：

`实验数据 → 模型与候选空间 → 实验优先级 → 湿实验 → 证据等级 → 下一轮设计`

P0 提供完整的 Design–Build–Test–Learn 主闭环；P1 与 P2 将相同思路扩展到材料接口和光控系统。Design mode 与实验后 Learn mode 分开保存，使公开 benchmark、实验反馈和后续迭代保持可追溯。
